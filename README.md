# DatamodelDesign — стандарт проектирования моделей данных ЛМД и КМД

Разработка корпоративного стандарта проектирования, документирования и сопровождения концептуальных (КМД) и логических (ЛМД) моделей данных: нормативный комплект (стандарт + регламент AS-IS + 18 приложений + машиночитаемый реестр 92 требований), процесс разработки (план Д0–Д8, реестр решений Р-xxx) и контур автоматизированного рецензирования (контур R).

## 4. Проверки и работа с репозиторием

```bash
# тесты проекта (58+22 + новые)
uv run --with jsonschema python -m unittest discover -s tests

# валидация записей реестра по схемам
uv run --with jsonschema python3 tools/registry_check.py check --file <запись.yaml>
uv run --with jsonschema python3 tools/registry_check.py selftest

# навигация комплекта (Р-041; в разработке)
uv run python tools/nav.py anchors|linkify|check
uv run --with python-docx python tools/build_docx.py --out dist/Комплект_стандарта.docx
```

Правила (Р-005, Р-033): любое изменение сопровождается коммитом с основанием (Р-xxx); каждый коммит публикуется push'ем в origin (`github.com/alexanderlazutkin/DatamodelDesign`, ветка main); force-push запрещён; `src/` не редактируется — после сессий сверять `git status` и SHA базы.
