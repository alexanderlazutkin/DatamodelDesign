# Д1: материалы решения ПВ-02 — профили ЛМД и модальность переноса

**Версия:** 0.3, 2026-10-10. **Статус:** решения приняты 2026-10-10 (Р-010, уровень — инициатор работ, инициативно; до подтверждения владельцем по ПВ-01). Файл — рабочая основа для переноса требований на Д3.
**Основание:** план 0.4, § 3 (ПВ-02), § 4 (Д1); С01 v0.8 — 2.4, 3.5, 3.6, 3.10, прил. А, Б; С03 (`LDM-009…015`, `LDM-018`, `LDM-021`, `LDM-027`, `LDM-032`); С04; Р-004 (таблица Б5); Р-008 (термины по С04).
**Ограничение:** новые ID и способ записи требований назначаются на Д3; здесь зафиксированы принцип применимости и решения.

## 0. Принятые решения (Р-010, 2026-10-10)

1. **Вариант А (профильная разметка при переносе) — принят с уточнением методолога:** категория области `ЛМД-Р` как ограничитель применимости требований **не используется**. Требования С03 — общие требования ЛМД: их обязательства применяются **во всех профилях**; реляционные понятия (PK, внешний ключ, идентифицирующая связь, ассоциативная сущность, нормальные формы) — **форма выражения** обязательства по умолчанию, адаптируемая профилем через прил. Б. Обозначения областей С04 (`ЛМД-Р` и др.) трактуются как границы буквального употребления реляционных терминов, а не как границы обязательств.
2. **Таблица применимости** переработана по этому решению (разд. 3, v0.3) и принимается как основа переноса на Д3.
3. **Способ записи смешанных требований** — построчно на Д3 по тесту атомарности С01 3.10 (один ID с профильными формами выражения в прил. Б либо разделение на отдельные обязательства).
4. **Повышение модальности рекомендаций отложено:** модальности переносятся по таблице Б5 (Р-004) без повышений; `LDM-010`, `LDM-018`, `LDM-021`, `LDM-027`, `LDM-032` остаются `recommended`. Повышение — отдельное решение методолога в будущем.

## 1. Суть вопроса

Требования С03 используют реляционные понятия как универсальные для всей ЛМД. С01 2.4 определяет профили моделирования; С04 ограничивает реляционные термины областью `ЛМД-Р`. Условие закрытия ПВ-02: PK/FK, разрешение M:M и нормализация не распространяются безусловно на все профили; повышение рекомендации оформляется решением.

**Разрешение (по решению методолога, Р-010):** безусловно на все профили распространяются **обязательства** (идентификация, явность ссылок и их контроль, мощность связей, явность M:M, обоснованность избыточности); **реляционная форма выражения** не навязывается профилям, в которых она не применяется буквально, — профиль задаёт адекватную форму выражения того же обязательства (правила — прил. Б). Тем самым реляционные понятия не переносятся буквально на документные/аналитические профили, а содержание требований действует universally.

## 2. Что говорят источники

- С01, 2.4: профили (корпоративная интеграционная, системная реляционная, аналитическая, документная/полуструктурированная); для каждого профиля — применимые конструкции и особенности структурной проверки (прил. Б); конфликт профилей разрешает архитектор данных с фиксацией в реестре решений.
- С04, обозначения областей: PK, внешний ключ (FK), кандидатный ключ, нормализация — `ЛМД-Р; ФМД-Р`; идентификатор, кардинальность, обязательность участия, суррогатный идентификатор — `ЛМД`/`КМД; ЛМД` (общие). По решению Р-010: области С04 — буквальность терминов, не границы обязательств.
- С03: модальности по исходнику — `LDM-009`, `LDM-011`–`015` — ОБЯЗАТЕЛЬНО; `LDM-010`, `LDM-018`, `LDM-021`, `LDM-027`, `LDM-032` — РЕКОМЕНДУЕТСЯ.

Применимость всех разбираемых требований — **все профили ЛМД**. Колонка «Реляционная форма выражения» показывает употребление по умолчанию (в системной реляционной модели и реляционных фрагментах); профильные формы выражения устанавливает прил. Б.

| ID | Исходная модальность | Обязательство (все профили ЛМД) | Реляционная форма выражения (по умолчанию) | Запись на Д3 |

## 4. Модальность переноса

Перенос — по таблице Б5 (Р-004) без изменений: ОБЯЗАТЕЛЬНО → `required`, РЕКОМЕНДУЕТСЯ → `recommended`. Повышение модальности — отдельное решение методолога (Р-010 п. 4: отложено).

## 5. Влияние на пилотный срез (план 0.4, § 7.1)

`LDM-009` входит в срез; применимость — все профили (решение Р-010), для ожидаемого реляционного объекта пилота применяется полная реляционная форма выражения. `LDM-023`/`LDM-027` — без ограничений.
