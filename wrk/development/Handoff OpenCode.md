- `src/` не редактировать; после каждой сессии `git status --short`, при ` M src/…` → `git checkout -- <файл>`, сверка: С03 = «Требования к ЛМД.md» SHA b40d1a38…; С02 = f571f296…; С01 = 54de4b5a… (зафиксированы в прил. Ф). Перед `prepare` контура R проверять каноничность src.

- `trash/`, сырые `review-runs/` — в работу не включать; ID замечаний и решения не перезаписывать; ID не переиспользуются.
- Реестр записей: canonical YAML по `wrk/standard/registry/README.md`; проверки — `python3 tools/registry_check.py check|selftest`; тесты — `uv run --with jsonschema python -m unittest discover -s tests` (60 тестов).
