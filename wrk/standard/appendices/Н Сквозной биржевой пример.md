# Приложение Н. Сквозной биржевой пример

**Версия:** 0.6-в4 (волна 4 Д7, рабочая редакция стандарта 0.6). Статус — **подготовительная часть** (методический рабочий черновик): цепочка «карта домена → КМД → ЛМД → правила → соответствия → проверка» показана на минимальном фрагменте вторичного рынка ценных бумаг. Полный пример — самостоятельная задача Д7 (план § 4, волна 4): готовых заготовок нет. Пример методический: новых обязательств не вводит (3.10); не является AS-IS-пилотом (ПВ-09).

## Н.1. Фрагмент карты домена

Домен «Торги» (вторичный рынок): заключение и исполнение сделок с ценными бумагами. Зависимости: домен «Ценные бумаги» (выпуски), домен «Расчёты» (исполнение). Форма — прил. Т.

## Н.2. Фрагмент КМД

Понятия: **Выпуск** (эмиссионная ценная бумага; экземпляр — выпуск с ISIN; определение с контрпримерами — CDM-010); **Торговая площадка**; **Допуск к торгам** (ассоциативная сущность: бумага × площадка, даты включения/делистинга, уровень листинга — CDM-018); **Заявка**; **Сделка** (бизнес-факт заключения; ≠ «Расчёт по сделке» — CDM-011); **Участник торгов** (роли: брокер покупателя / брокер продавца — CDM-014, CDM-028).

Связи (спецификация с интервалами — прил. В):

```
Выпуск 1..* ←допускает→ 0..* Допуск к торгам 1..1 ←на→ 0..* Торговая площадка
Сделка 1..* ←порождена→ 0..1 Заявка        (необязательность: внебиржевые сделки)
Сделка 1..1 ←заключает→ 1..1 Участник (брокер продавца)   — и симметрично покупатель
```

Разметка ИОД: сущности «Клиент», «Сделка», «Позиция» — кандидаты разметки (CDM-032, прил. И; статусы установленности).

## Н.3. Фрагмент ЛМД

Детализация: концептуальная «Сделка» → логические «Сделка» и «Расчёт по сделке» (соответствие 1:N — 8.4, LDM-003); «Допуск к торгам» — ассоциативная сущность M:M (LDM-015); идентификация: «Выпуск» — ISIN (альтернативный: тикер в пределах площадки — LDM-009); домен «Код валюты ISO 4217» переиспользуется (LDM-027, прил. Е); межсистемный линк «номер сделки во внешнем репозитарии» (LDM-025).

## Н.4. Правила и их преобразование

| Правило (КМД) | Преобразование (8.8) | Механизм/состояние (8.9, прил. С) |
|---|---|---|
| «Номер сделки уникален в пределах сессии площадки» | Сохранено | Контроль приложения — частично (дубли во внебиржевом контуре — реестр вопросов) |
| «Количество в заявке кратно лоту» | Сохранено | Проверка приложения — реализовано |
| «У выпуска не может быть двух действующих ISIN» | Сохранено | Декларативное ограничение — реализовано |

## Н.5. Соответствия и проверка

Соответствия КМД↔ЛМД зафиксированы (Н.3); несопоставленных элементов нет. Проверка: формальная (паспорт — прил. Г), семантическая (определения), сценарная (CDM-042): сплит акций, конвертация выпуска, делистинг, перевод между счетами депо — проверяют разделение «Выпуск / партия / права» (CDM-011). Диаграммы — по прил. В (Mermaid `erDiagram`; тройное соответствие — 2.8).

## Н.6. Резерв полного примера

Полная карта домена, все представления, каталог сценариев и протокол проверки — при выполнении примера как самостоятельной задачи (вход: решения по охвату; после ПВ-06 вопрос о включении примера ГК рассматривается отдельно).
