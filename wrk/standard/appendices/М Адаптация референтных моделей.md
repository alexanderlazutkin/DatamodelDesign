# Приложение М. Адаптация референтных моделей

**Версия:** 0.7-лит1 (Р-054: применение серии библиоаудита — М.2 дополнено методикой сопоставления «подзадача → паттерн» (К-5) и чек-листом верификации применимости (К-6), источники — review/02; М.4 дополнено структурой перечня референсов (К-16), review/09; аргумент 50/25/25 — К-15, review/08). ## М.1. Назначение

Порядок анализа и адаптации референтных (отраслевых, стандартных) моделей при проектировании (4.5, 8.3). Референтная модель — ориентир, а не нормативное основание (1.7): заимствование не переносит обязательств источника автоматически.

## М.2. Порядок адаптации

1. **Выбор источника и версии** — фиксируются явно; условия использования материалов (лицензия, права) проверяются до заимствования.
2. **Проверка применимости** — соответствие охвату задачи (5.2) и профилю (2.4); неподходящие фрагменты не заимствуются.
2а. **Поиск кандидата-паттерна (методика, Р-054 — К-5, review/02).** Охват разбивается на функциональные подзадачи; для каждой ищутся паттерны-кандидаты тремя эвристиками подобия: *буквальное подобие* (сущность подзадачи — подтип/синоним сущности паттерна), *абстракция* (отношение подзадачи — частный случай отношения паттерна; «abstraction is to relations as literal similarity is to entities»), *аналогия* (параллель отношений при несходных сущностях). Сопоставление конструктов ведётся 1:1 с фиксацией неточностей; уверенность каждого сопоставления маркируется статусом по T-037.
2б. **Верификация применимости паттерна (чек-лист, Р-054 — К-6, review/02).** Поверхностная оценка → глубокая проверка по трём осям (атрибуты, сущности, связи) → фиксация различий → разрешение каждого различия (принять / адаптировать / отказаться) → признание применимости либо неприменимости → финальная верификация по подзадаче в целом.
3. **Анализ соответствий** — сопоставление «элемент источника → элемент модели» по видам: прямое заимствование / адаптация (изменение с основанием) / расширение (добавление к заимствованному) / отказ (расхождение с основанием).
4. **Фиксация смысловых отклонений** — каждое отклонение от трактовки источника сопровождается основанием (8.3); молчаливое переозначение не допускается.
5. **Реакция на новые версии источника** — выход новой версии — триггер анализа влияния (8.11): перечень заимствований из 8.3 → оценка затронутых фрагментов → решение о синхронизации либо фиксация расхождения.

## М.3. Примеры соответствий (иллюстративные)

- Прямое заимствование: классификация типов ценных бумаг из нормативного классификатора ([[Правила#^CDM-026|CDM-026]]) — с фиксацией владельца-источника.
- Адаптация: сужение отраслевого перечня статусов сделки до используемых в охвате — с основанием «фактические состояния процесса».
- Отказ: термин источника расходится с утверждённым термином глоссария (8.2) — фиксируется расхождение, принимается корпоративный термин.

## М.4. Ограничение объёма (ПВ-11)

Работа с источниками ведётся по вопросам, а не сплошным переводом: для каждой задачи фиксируются разрешённые источники, версии и лицензии. Ориентир объёма (Р-054 — К-15, review/08): ~50 % корпоративной модели составляют универсальные конструкции, ~25 % — отраслевые, ~25 % — специфичные для организации — универсальные референсы приоритетны.

Структура перечня принятых референтных моделей (Р-054 — К-16, review/09): (а) универсальные структуры (стороны, продукты, заказы/соглашения, доставка, работа, счета, учёт); (б) отраслевые модули по релевантным организации отраслям; (в) иные источники (FIBO и др.). Для каждого модуля: назначение, версия, лицензия, ответственный за адаптацию (по М.2). [Заполняется: перечень принятых референтных моделей организации]
