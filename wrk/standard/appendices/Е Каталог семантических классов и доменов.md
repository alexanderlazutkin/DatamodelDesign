# Приложение Е. Каталог семантических классов и доменов

**Версия:** 0.5-в3 (волна 3 Д7, рабочая редакция правил 0.5). Статус — **черновик-основа**: структура и начальный состав зафиксированы; наполнение данными организации (владельцы, полные перечни) — [Заполняется: после назначения владельцев, ПВ-01; вход волны 3 — данные организации].

## Е.1. Назначение

Каталог связывает повторно используемые типы атрибутов единым смыслом и поддерживает согласованность определений ([[Правила#^LDM-027|LDM-027]], [[Правила#^LDM-007|LDM-007]], [[Правила#^LDM-008|LDM-008]]): домен — имя, смысл, допустимые значения либо ограничения, формат, единица измерения; семантический класс — смысловая роль атрибута (7.4). До утверждения полного каталога организации (Е.4) допускается вводить локальные домены модели с явной пометкой локальности; при повторном использовании такой тип атрибута сопровождается ссылкой на локальный домен, а включение домена в корпоративный каталог оформляется предложением в реестре вопросов (4.8).

## Е.2. Структура записи

**Домен**: идентификатор; имя; смысл; допустимые значения либо ограничения; формат; единица измерения; владелец; версия; правила изменения.

**Семантический класс**: имя; смысл; типовые ограничения; связь с классами доменов.

## Е.3. Начальные классы (по тезисам v0.7/7.4; уточнение — при наполнении)

| Класс | Смысл | Типовые уточнения |
|---|---|---|
| Сумма | Денежная величина | Валюта, точность, база котирования |
| Цена | Стоимость единицы | Валюта либо процент от номинала (шкала) |
| Количество | Числовое количество | Единица измерения, кратность лоту |
| Ставка | Относительная величина за период | База (год/иное), тип |
| Процент | Доля в процентах | Шкала (0–100 / 0–1) |
| Код | Кодовое обозначение | Классификатор-владелец (7.9) |
| Идентификатор | Бизнес-идентификатор объекта | Область уникальности (6.4) |
| Дата/время | Момент либо период | Часовой пояс, календарь |

## Е.4. Начальные домены (иллюстративные)

- «Код валюты ISO 4217» — переиспользуется атрибутами цен, лимитов (пример [[Правила#^LDM-027|LDM-027]]).
- «Тип ценной бумаги» — внешний нормативный классификатор (пример [[Правила#^CDM-026|CDM-026]]).

## Е.5. Правила ведения

Повторное использование типа атрибута сопровождается ссылкой на домен ([[Правила#^LDM-027|LDM-027]]); локальный домен допускается с обоснованием. Домены версионруются; анализ влияния изменений домена — 8.11. Каталог ведётся как управляемый реестр ([[А Каталог требований и схема записей проверки#А.10. Правила ведения|прил. А.10]]) и включается в манифесты выпусков компонентом.
