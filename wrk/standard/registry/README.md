# Реестр требований: правила ведения

**Версия:** 0.1-д3 (2026-10-11). Реестр — мастер-источник формулировок (С01 3.11).
Формат — YAML (решение Д2, Р-012); схемы — JSON Schema draft 2020-12 в YAML-форме.
Пилотный выпуск `0.2-д3` (draft, Р-016): 35 требований, 33 строки матрицы AS-IS.

## Расположение

| Что | Где |
|---|---|
| Схемы записей | `schema/*.schema.yaml` |
| Испытательные примеры | `examples/positive/`, `examples/negative/` |
| Записи требований | `requirements/` (`<id>.r<revision>.yaml`; пилотный срез — Р-016) |
| Матрица применения AS-IS | `asis/` (`asis-<id>.yaml`; строки выпуска 0.2-д3) |
| Манифесты выпусков | `releases/` (`release-0.2-д3.yaml`, draft) |
| Записи результатов проверки (с Д5) | `verifications/` (план) |

## Канонический стиль YAML

- кодировка UTF-8; отступы — 2 пробела; без табуляций;
- ключи — без кавычек; строки формулировок — блоковые скаляры `>-`;
- порядок полей записи — как в соответствующей схеме (стабильный diff);
- одна запись — один файл; имя: `<id>.r<revision>.yaml` (требования), прочие — по типу записи;
- комментарии (`#`) допускаются; записи реестра (не примеры) сопровождаются комментарием-основанием только при переносе (ссылка на решение Р-xxx);
- даты — `ГГГГ-ММ-ДД`; ID — паттерны схем (`GEN|CDM|LDM-###`, `PR-###`, `V-######`, `EV-####`).

## Проверка

```
python3 tools/registry_check.py check --file <запись.yaml> [<запись2.yaml> …]
python3 tools/registry_check.py selftest   # испытательный набор схем
```

Код 0 — формальная проверка пройдена; это не утверждение содержания.

## Семантика (кратко; нормативно — прил. А С01)

- отсутствие оси применимости — «применимо ко всем» значениям оси; значения оси — дизъюнкция, оси — конъюнкция;
- `undefined` — явная неопределённость: только `status: draft`, единственное значение оси;
- `stage` — классификатор 4.2 С01 (1–8), не хронология;
- `mode` — состояние фрагмента (`to-be`/`as-is`); смешанный режим — по состоянию фрагментов, значения `mixed` нет;
- записи результатов проверки и свидетельства — отдельно от требований; матрица AS-IS не содержит результатов проверки моделей.
