## 3. Кандидаты дополнений

**К-17. Уровни общности паттернов в прил. Р (методическая рамка; связь с ПВ-02).**
Каждый паттерн прил. Р приводится в 2–3 уровнях общности (конкретный → параметризованный → обобщённый) с указанием выгод/издержек уровня: конкретный — наглядность для бизнеса и прямые правила в модели; обобщённый — гибкость и стабильность. Выбор уровня — по аудитории представления и назначению фрагмента; подмена уровня (plug-and-play) не меняет бизнес-смысла.
Основание: «The Different Pattern Levels»; таблица «Easier to understand model… / More flexible…» (гл. 1); «there is a “plug-and-play” nature of these patterns… Think of patterns as components that can be substitutes for each other».

**П-17. Рекурсия с типизированными правилами связей (прил. Р; усиление CDM-029).**
Для рекурсивных иерархий: связь «родитель—потомок» уточняется типом связи; набор допустимых пар типов (какой тип может быть родителем какого) фиксируется правилами (уровень «Level 3 Recursive Pattern with Rules»).
Основание: гл. 4 «Level 3 Recursive Pattern with Rules» (по оглавлению и принципам гл. 1).

**Заметки:** различение декларативных/контекстных ролей → в П-2/Р.3; статусы уровнями (атрибут → история → категоризация) → в П-6/Р; несколько схем классификации и rollups → к П-12; «гибкие части адреса» → к прил. Е; гибридный паттерн (конкретное + обобщённое с представлениями) → к 11.4; социализация паттернов → к Д8.
