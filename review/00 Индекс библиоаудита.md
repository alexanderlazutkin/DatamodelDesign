# Индекс серии библиоаудита

**Версия:** 0.2 (Р-053). **Статус:** серия завершена (рецензии 01–12 + сводка 99 готовы). Порядок источников — по перечню базы знаний «Проектирование моделей данных» (решение пользователя 2026-10-18); привязка к волнам Л1–Л3 этапа Д-лит (Р-047) сохраняется для целевых областей комплекта.

## 1. Назначение серии

Пофайловые рецензии по каждому источнику литературы: проверка соответствия действующих требований Правил (92 approved + словарь + приложения) материалу источника и фиксация кандидатов дополнений — для последующей оценки человеком и применения через действующие процедуры (draft → контур R → approved; решения Р-xxx). Литература — методические источники (1.7): нормативной силы не имеет. Анти-галлюцинация (Р-047): каждый кандидат сопровождается дословной цитатой (источник + глава/раздел) из базы знаний.

Единый шаблон рецензии: карточка источника → тематическая сверка с вердиктами Р-047 (покрыто / частично / пробел / конфликт / вне охвата) → кандидаты дополнений (уточнения формулировок, паттерны/антипаттерны, термины, методические заметки) → конфликты и осознанные ограничения → резюме с приоритетами.

## 3. Регламент серии

1. Порядок — сверху вниз по перечню базы знаний (решение пользователя 2026-10-18); файлы именуются по номеру позиции.
2. Каждая рецензия — самостоятельный результат; коммит на файл (Р-005, основание — Р-053).
3. Границы фазы: комплект (`wrk/standard/`) не изменяется; кандидаты применяются отдельными решениями после оценки человеком; повышение модальностей — только владелец правил (Р-010 п. 4).
4. Пересечения источников (например, паттерн «сторона» у Ponniah/Hay/Silverston) фиксируются в рецензиях перекрёстными ссылками; консолидация — в сводке 99.
5. Источники вне базы знаний (Simsion, Teorey, Дейт, DAMA-DMBOK — состав волн Л2/Л3 по Р-047) в серии не рассматриваются; при пополнении базы — решение Р-xxx о расширении серии.
