## 3. Кандидаты дополнений

**К-8. Категория (union type) — материал к разбору ПВ-05 (включается вместе с П-9 рецензии 01).**
Формулировка для прил. В/Р после разбора: категория — подтип, определённый над объединением двух и более супертипов; каждый экземпляр принадлежит ровно одному супертипу; наследуются атрибуты, общие для всех супертипов; изображается символом объединения с дугой принадлежности.
Основание: «A **union type** (or **category**) represents a subclass that is a subset of the UNION of two or more distinct superclasses… An instance of a category must belong to exactly one of the superclasses; The category inherits attributes common to all superclasses; Each instance maintains its identity in the originating superclass».

**К-9. Сводка конструкций EER для легенды прил. В (методическое; без новой нормы).**
Перечень отображаемых конструкций нотации: подтип/супертип с текстовыми правилами полноты/пересечения; дискриминатор (attribute-/user-defined); наследование идентификатора; категория (после ПВ-05); агрегация; слабая сущность и идентифицирующая связь. Примечание: переопределение унаследованных атрибутов в EER не поддерживается — при проверке моделей с «переопределением» фиксировать вопрос.
Основание: «**Overriding**: Generally not supported in EER (unlike object-oriented models)».

**Термины:** «категория (union type)» — не вводить до ПВ-05 (согласовано с рецензией 01); «агрегация» — рабочий термин кандидата П-7.

## 4. Конфликты и осознанные ограничения

- **Конфликты с Правилами: не выявлены.**
- **Терминологический конфликт между источниками серии:** статья 03 (Wikipedia/Elmasri) определяет category как union-подтип над несколькими супертипами; статья 04 (Baeldung, рецензия ниже) использует «categories» для дискриминаторного деления на подтипы — разные понятия под одним именем. Для словаря Правил термин «категория» не вводится до разрешения на ПВ-05; в рецензиях серии употреблять только в смысле Elmasri (03).
- **Вне охвата:** история EER, обзор инструментов (перечень средств — вне регламента; критерий поддержки ограничений disjointness/completeness — заметка для В).
